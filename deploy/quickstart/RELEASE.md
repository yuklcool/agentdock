AgentDock 0.3.4：移除旧个人智能体绑定机制，统一工作空间 API Key 边界。

- 删除个人密钥页面和接口、模板“我的智能体”入口及固定绑定逻辑。
- 工作空间密钥仅表示服务身份，不注入用户 ID，也不继承创建者权限。
- 保留容器用户归属、管理员代建、多容器、模板、任务、会话和事件功能。
- 新迁移 0032 删除旧用户绑定密钥、废弃绑定表及密钥归属字段；不会将旧密钥提升为空间级密钥。
- 已有私有容器、任务和数据卷保留，可通过用户登录会话访问。工作空间 API Key 继续访问共享资源。

升级前备份数据库。保留原 .env 和数据卷，将 AGENTDOCK_VERSION 改为 0.3.4，执行：

```bash
docker compose --profile images pull
docker compose up -d --no-build --wait
```

启动流程自动执行迁移。旧用户绑定密钥会失效且无法恢复，回滚旧程序需要恢复升级前数据库备份；downgrade 不重建被删除的数据。已有智能体容器无需重建。

8 个组件统一发布 0.3.4 镜像标签，Linux amd64。本版仅清理旧机制，未引入主容器或新的按用户代理访问方案。
