AgentDock 0.3.10：修复 Nanobot 模板初始化文件配置区被压缩隐藏的问题。

- 修复模板编辑页的纵向 Flex 布局：表单子项保持内容高度，由左侧表单统一滚动，初始化文件卡片不会被压成一条线或裁掉编辑按钮。
- 六个初始化文件仍在 MCP servers 下方，支持在线编辑、上传替换和恢复 Nanobot 默认。
- 新增真实 Chromium 浏览器回归，在 1440、1100 和 390 像素宽度下检查六个文件的按钮未被裁切，并逐一编辑、保存。
- 保留 0.3.9 的原生初始化、创建快照与运行时模型配置优先级，以及 0.3.8 的 MCP 和自定义 OpenAI 兼容接口适配。

全部 8 个组件统一发布为 0.3.10，平台为 Linux amd64。

将现有部署 .env 中的 AGENTDOCK_VERSION 改为 0.3.10，保留现有密钥和 Volume，然后执行：

```bash
docker compose --profile images pull
docker compose up -d --no-build --wait
```

更新后刷新管理页面即可使用修复后的模板编辑页。本次修复不需要重建已有智能体容器，也不会重新写入其初始化文件。模板文件覆盖仍然只应用于以后新建的 Nanobot 容器和新 Volume；内置模板需先克隆后编辑。
