AgentDock 0.3.3：配额与审计页面重构。

- 配额按实例、工作空间每日、单用户每日分为三张卡片。每日预算 0 明确显示为不限额。
- 审计列表显示中文操作、用户姓名与登录标识、资源名称，可筛选操作、操作者和资源名称。
- 详情弹窗展示技术 ID；接口不再返回原始 details，避免泄露提示词、密钥、密码和任务结果。
- 保持管理员/Owner/Staff 权限，并在资源名称解析时校验工作空间范围。
- 当前用户模型尚无 account，接口返回 account: null，界面暂用登录邮箱。未引入用户账号迁移。
- 任务尚无独立标题，显示所属容器名称加“的任务”，不会截取提示词；提交记录显示“已提交”，不代表任务执行成功。

升级：保留原 .env 和数据卷，将 AGENTDOCK_VERSION 改为 0.3.3 后执行：

```bash
docker compose --profile images pull
docker compose up -d --no-build --wait
```

刷新浏览器，进入 Settings → 配额与审计。已有智能体容器无需因本功能重建。8 个组件统一发布 0.3.3 镜像标签，Linux amd64。

验证包含真实 PostgreSQL 名称关联、跨工作空间隔离和敏感字段过滤，以及桌面/手机页面交互检查。
